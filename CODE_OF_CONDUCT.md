# Code of Conduct

## Our Commitment

We are committed to maintaining a professional, respectful, inclusive and learning-focused environment for everyone who participates in this synthetic HR analytics project.

Participation includes opening issues, submitting pull requests, reviewing work, discussing analytical methods, contributing documentation and sharing participant solutions.

## Expected Behaviour

Participants are expected to:

- communicate respectfully and professionally;
- provide constructive, evidence-based feedback;
- respect different levels of technical experience;
- acknowledge original work and sources;
- use only synthetic or properly authorised data;
- protect privacy, credentials and confidential information;
- document assumptions, limitations and transformations;
- avoid discriminatory, intimidating or demeaning language;
- follow the participant submission and review process;
- accept maintainer decisions regarding quality, security and repository scope.

## Unacceptable Behaviour

The following behaviour is not acceptable:

- harassment, threats or personal attacks;
- discriminatory comments or conduct;
- publishing personal, confidential or private information;
- submitting real employee records to this public repository;
- exposing passwords, API keys, tokens or private URLs;
- plagiarism or unattributed copying;
- intentionally misleading analysis or fabricated validation evidence;
- using project outputs to automate real hiring, termination, promotion, discipline, medical or other high-impact employment decisions;
- bypassing branch protection, review requirements or security controls;
- repeatedly disrupting reviews, issues or pull requests.

## Project-Specific Responsibility

KAS Ltd., XYZ Export Processing Zone, all employees, buyers, incidents and outcomes in this repository are fictional.

Contributors must not present synthetic analysis as a verified real-world company result. Correlation, simulated improvement and model output must not be represented as proven causality.

## Enforcement

The maintainer may edit, hide, reject or remove contributions that violate this Code of Conduct. Depending on severity, the maintainer may also close issues, close pull requests, remove contributor recognition, restrict participation or report serious abuse through GitHub’s platform mechanisms.

## Reporting

Do not disclose sensitive reports publicly. Use GitHub private vulnerability reporting for security matters when available. For other conduct concerns, contact the repository maintainer through an appropriate private channel.

All reports will be reviewed in good faith, with reasonable confidentiality and attention to the safety of affected participants.

## Scope

This Code of Conduct applies within repository discussions, issues, pull requests, reviews, participant submissions and other project-related public interactions.
