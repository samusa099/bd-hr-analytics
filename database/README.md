# Database Output

Run:

```bash
python scripts/build_sqlite_database.py
```

The generated local database will be:

```text
database/bd_hr_analytics.sqlite
```

The database is reproducible from the repository CSV files and SQL scripts. It contains only synthetic portfolio data.

A generated `.sqlite` file may be attached to a release when convenient for learners, but the source of truth remains the CSV and SQL workflow.
