# Participant Solution Directory

Create participant work only under:

```text
participant-submissions/solutions/<github-username>/<challenge-id>/
```

Do not place solution files directly in this directory.

Each participant folder must follow the governance in [`../../docs/PARTICIPANT_SUBMISSION_GOVERNANCE.md`](../../docs/PARTICIPANT_SUBMISSION_GOVERNANCE.md) and target the `participant-review` branch.

The presence of a solution in this directory does not imply endorsement, certification or production readiness.
