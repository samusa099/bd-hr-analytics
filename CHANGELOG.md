## [0.4.0] — 2026-07-29

### Added

- professional Q1–Q4 KAS Ltd. HR Business Partnership and operating-transformation case;
- integrated 10–16 hour analytics challenge covering data assurance, SQLite, DBeaver, Excel, Power BI, Looker Studio, refresh governance and an HRBP decision memo;
- controlled `participant-submissions/` workspace, templates and review rubric;
- dedicated `participant-review` branch and participant-target validation;
- required `validate-project` and `security-checks` branch checks;
- practice SQLite database for local analytical work;
- release-based practice-package distribution model.

### Changed

- repositioned Musa from Senior Executive through an acting HRBP assignment to Assistant Manager — HR Business Partnering & People Analytics;
- redesigned the README around the KAS Ltd. case, integrated challenge and participant workflow;
- changed downloads from a repository ZIP link to the GitHub Releases page;
- separated public source and documentation from private administrative rulesets;
- prepared a practice-only archive containing CSV, JSON, SQLite, Excel, notebook, SQL and DAX assets;
- updated the project version and release documentation to `v0.4.0`.

### Removed

- `bd-hr-analytics-unified-project.zip` from the `main` branch;
- workflow and script that committed a generated release ZIP directly to `main`;
- public ruleset JSON templates;
- public ruleset implementation and recovery documents;
- governance, changelog, release-note and Git metadata files from the downloadable practice package.

### Release Asset

```text
bd-hr-analytics-practice-files-v0.4.0.zip
```

The private administrative package `bd-hr-analytics-private-rulesets-v0.4.0.zip` is not a public release asset.
